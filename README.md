# Breaking Beer · Carta digital

Carta web de Breaking Beer (bar cultural, San Juan). Los precios se leen solos de la carta QR de Fudo todos los días a las 20 hs y se publica con GitHub Pages.

- `plantilla/` diseño y textos · `scripts/` lector de precios · `docs/` carta publicada · `data/` últimos precios conocidos.
